# 🐍 Python Word Replacement Program

## 📌 About the Project
This is a beginner-level Python project created while learning Python programming. It takes a sentence from the user, replaces a specified word with another word, and demonstrates different string operations and character conversions.

## ⚙️ Features
- Takes a sentence as user input.
- Calculates the length of the sentence using `len()`.
- Replaces words using the `replace()` method.
- Iterates through each character using a `for` loop.
- Converts characters into Unicode values using `ord()`.
- Converts Unicode values back into characters using `chr()`.

## 🛠️ Concepts Used
- Python Strings
- User Input (`input()`)
- String Length (`len()`)
- String Replacement (`replace()`)
- Escape Sequences
- For Loops
- Character Conversion (`ord()` and `chr()`)



## 🎯 Purpose
The purpose of this project is to practise Python fundamentals and understand how built-in string methods and character conversion functions work.
